# ContinuumLib

ContinuumLib is being rebuilt as a compiler-first Minecraft API compatibility system. Mod developers write native code for one declared Minecraft environment; ContinuumLib analyzes that code and resolves supported operations for configured target environments.

The active implementation follows the conventional package root:

```text
src/main/java/com/kyroxova/continuumlib/
```

The previous prototype is preserved at `backup/src/` and is excluded from active compilation.

See [Development Status](Development-Status) for implemented capabilities.
